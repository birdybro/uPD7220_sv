# Specification traceability matrix

This matrix is the authoritative inventory of externally visible behavior for
the synthesizable core. A row marked **Researched** has a primary-source
statement but does not imply implemented or verified behavior. Rows progress
through **Implemented**, **Unit verified**, and **Cycle verified** only when the
listed evidence exists. **Open** means that the surviving primary sources do
not yet resolve a digital-edge-level detail; the architectural behavior in the
row remains required.

Page citations use the printed page number where one exists and include the PDF
page for image-only appendices. The Intel preliminary data sheet is revision
210655-002 (June 1983); the Intel application manual is 230685-001 (July 1983);
the NEC user manual is Stock No. 500230 / NECEL-000079-1285 (December 1985).
